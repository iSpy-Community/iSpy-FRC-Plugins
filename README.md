## Submit a Plugin

Have you built a plugin for iSpy-FRC? We'd love to see it!

1. Read the plugin contribution guidelines.
2. Ensure your plugin follows the iSpy-FRC plugin interface and configuration requirements.
3. Open a pull request adding your plugin to this directory.
4. Respond to review feedback and update your submission as needed.

**Keep your plugin in your own repository.** This directory links to community projects; it does not require you to transfer ownership of your code.

## Security

Only install plugins from developers and repositories you trust. Community listings do not guarantee that a plugin is safe.

Please report security vulnerabilities privately to the relevant project maintainer rather than publishing exploit details in an issue.
